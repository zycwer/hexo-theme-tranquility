欢迎来到 **Tranquility（致远）** 主题演示站。本站由 GitHub Actions 在每次提交后自动构建，展示了主题的绝大部分特性。

> 宁静致远 —— 不追热点，不加繁饰，只把每一个特性做到恰到好处。

## 特性速览

| 特性 | 状态 | 说明 |
| --- | --- | --- |
| 项目展示 | 已开启 | 首页「我的项目」卡片，见下方 |
| 技能展示 | 已开启 | 分组熟练度进度条 / 标签 |
| 公告横幅 | 已开启 | 导航下方可关闭公告条，内容更新后自动重新展示 |
| 建站时长 | 已开启 | 页脚实时秒级跳动 |
| 深色模式 | 已开启 | 跟随系统，可手动切换 |
| 本地搜索 | 已开启 | 右上角放大镜，无需外部服务 |
| PWA | 已开启 | 可安装到主屏幕，离线可访问 |
| CSP 安全策略 | 已开启 | 查看本页源码可见 meta CSP |
| 资源指纹 | 已开启 | 所有静态资源带 `?v=` 内容哈希 |
| Mermaid 图表 | 已开启 | 见[图表演示](/posts/mermaid-diagram/)一文 |
| MathJax 公式 | 已开启 | 见[公式演示](/posts/mathjax-formula/)一文 |
| 相关文章 | 已开启 | 文末推荐 |
| 赞赏 | 已开启 | 文末「喜欢作者」 |

## 继续探索

- 首页向下滑动：项目、技能、时间线、最近更新等区块
- 点击右上角搜索图标体验本地搜索
- 切换深色模式，观察全站配色与一言、评论区联动
- 阅读 [Markdown 基础排版](/posts/markdown-syntax/) 查看排版细节

```text
npm install hexo-theme-tranquility
```

一行命令，把这份宁静带回你的博客。
