## Tranquility（致远）

一款为个人主页与多学科领域博主设计的 Hexo 主题。

- **源码**：[github.com/zycwer/hexo-theme-tranquility](https://github.com/zycwer/hexo-theme-tranquility)
- **文档**：[docs.qwrcb.top](https://docs.qwrcb.top)
- **安装**：`npm install hexo-theme-tranquility`

本站为特性演示站，展示主题的绝大部分能力：个人主页区块（项目 / 技能 / 时间线）、公告横幅、建站时长、本地搜索、PWA、深色模式、Mermaid、MathJax、CSP 安全策略与资源指纹等。

演示内容由 GitHub Actions 在每次提交后自动构建，你看到的永远是主题的最新状态。
